# Ghost Engine releases

Downloads of Ghost Engine, an AI-powered game editor for macOS.

- **Download:** the newest zip under [Releases](https://github.com/nurdiloyd/ghost-engine-releases/releases/latest). Unzip it and move *Ghost Engine.app* to Applications.
- **Requires:** macOS 26 or later, the Xcode Command Line Tools (`xcode-select --install`), and your own Anthropic API key.
- **Updates:** Ghost Engine checks for new builds itself. `appcast.xml` in this repository is the feed it reads.

Each build is signed with a Developer ID, notarized by Apple, and its update archive is signed with an EdDSA key only the developer holds.
